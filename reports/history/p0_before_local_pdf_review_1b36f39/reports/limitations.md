# Limitations

1. P0 is incomplete: only four primary studies have scoped reviews; mandatory
   HEFT/CPOP and PEFT originals remain unavailable. Protocol documents are drafts.
2. No simulator, scientific workload generator, B1–B5 scheduler, candidate,
   independent physical-trace validator, statistics implementation or performance
   plotting workflow has been implemented or validated. Package scaffolding is
   explicitly not those components.
3. The 17 passing tests exercise governance, metadata identities and entry locks.
   They do not establish simulation correctness or any scheduling benefit.
4. No workload has been materialized from any scientific partition, including
   CALIBRATION. Source papers' results and prior-project results are not samples.
5. Hardware metadata is from this cloud instance; no automotive hardware
   measurements, WCET guarantee, safety certification or measured energy exist.
6. Reviewed-source PDFs are restored from public URLs with SHA256 checks into
   an ignored cache. Future source-host unavailability or changed bytes will
   cause a visible setup failure, not a silently substituted manuscript.
7. Saved environment configuration is a draft. Publication and restoration in a
   new cloud task are separate platform actions and have not been claimed.
